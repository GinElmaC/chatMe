# 千语例子数据

这个目录包含千语应用的示例数据，作为项目的一部分被提交到 Git。

## 文件说明

### 聊天记录示例
- `chat_history_example_1.json` - 一个简单的初次对话示例

### 人格设定示例
- `personality_example.json` - 示例人格设定

### 浓缩历史示例
- `chat_history_zip_example.json` - 示例浓缩历史

### 用户印象示例
- `user_impression_example.json` - 示例用户印象

### 系统配置示例
- `system_config_example.json` - 示例系统配置

## 如何使用

如果你想使用这些例子作为初始数据，可以：

1. 复制 `chat_history_example_1.json` 到 `data/chat_history/` 目录并重命名
2. 复制 `personality_example.json` 到 `data/personality/` 目录并重命名为 `personality.json`
3. 复制其他文件到相应位置（如果需要）

## 注意

这些文件只是示例，**不要**在实际使用中暴露个人信息或敏感数据！
